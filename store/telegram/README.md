## Description (`/setdescription`, до 512 символов — здесь 410)

Видно в пустом чате до нажатия «Старт».

```
Звездица считает твой личный месяц. Он начинается не первого числа, а в день, когда Луна возвращается туда, где была при твоём рождении.

Ответь на 4 вопроса (дата, время и город рождения, где ты сейчас), и я расскажу, чего тебе захочется в этот месяц и чего захочет жизнь. Пришлю карту неба и напомню, когда начнётся новый месяц.

Прогноз — повод посмотреть на свой месяц со стороны, а не предсказание судьбы.
```

## About (`/setabouttext`, до 120 символов — здесь 105)

```
Прогноз на твой личный месяц: от возвращения Луны в точку рождения до следующего. Напомню о новом цикле ✨
```

## Аватар (`/setuserpic`)

`zvezditsa-bot-avatar.png` (640×640) — отправить как фото, не как файл.
Пересобрать после смены иконки: `.venv/bin/python store/telegram/make_avatar.py`.
`preview-circle.png` — только превью круглой обрезки, не загружать.

## Команды

В BotFather не заводить: бот сам задаёт меню при запуске (`my_astro_bot/bot/main.py`).

## Примечания

- Тексты продолжают приветствие и `/help` бота (`my_astro_bot/bot/handlers/common.py`) — при их правке сверить.
- Слово «лунар» не используем (знак LUNARO №975382).
- «Бесплатно» не пишем: в коде есть оплата Telegram Stars (сейчас `PAYWALL_ENABLED=false`).
