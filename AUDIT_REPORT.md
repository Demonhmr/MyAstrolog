# 🔍 Аудит проекта MyAstro Bot — v2 (2026-07-19)

Первый аудит (v1) выявил 13 проблем — все исправлены в релизе v3 (миграция на pyswisseph).
Этот документ — итог второго аудита. **Все пункты ниже исправлены** в ветке `modernization`.

## Исправленные критические баги

| # | Проблема | Файл | Исправление |
|---|----------|------|-------------|
| 1 | `logging` используется без импорта → NameError при AmbiguousTimeError (рождение в ночь перевода часов) | `core/geocoder.py` | `import logging` + обработка NonExistentTimeError |
| 2 | Синхронный геокодинг блокировал event loop — бот замирал для всех пользователей | `bot/handlers/registration.py` | Вызов через `run_in_executor` |
| 3 | `TimezoneFinder()`/`Nominatim` создавались на каждый запрос | `core/geocoder.py` | Синглтоны уровня модуля, timeout=5s |
| 4 | matplotlib pyplot не потокобезопасен — параллельные пользователи портили карты | `core/chart_generator.py` | OO API: `Figure` + `FigureCanvasAgg` |
| 5 | Сетевые ошибки геокодера (таймаут) не перехватывались — пользователь получал тишину | `geocoder.py`, `registration.py` | `GeopyError` → понятное сообщение, повтор в том же состоянии |

## Исправленные логические/методологические проблемы

| # | Проблема | Исправление |
|---|----------|-------------|
| 6 | Поиск лунара от «сегодня −14 дней» мог выбрать будущий цикл вместо текущего | Берётся последний возврат ДО текущего момента — цикл всегда содержит сегодня |
| 7 | Динамика месяца показывала только знаки ASC/MC; методика требует дома управителей | Добавлены управители (современные) и их дома со сферами жизни |
| 8 | Не было самопроверки «сумма баллов = 26» из методики | `AstroCalculator._verify_totals` — warning в лог при расхождении |
| 9 | README/ARCHITECTURE описывали ephem, два города и 5 состояний FSM — код другой | Документация приведена к актуальному коду (один город — решение владельца) |

## Исправленные мелочи

- `datetime.utcnow()` → `datetime.now(timezone.utc)`
- Удалены неиспользуемые зависимости: `pydantic`, `python-dateutil`, `requests`; импорты `math`/`pytz` (astrology), `os` (interpretator)
- Пути к `data/` — через `Path(__file__)`, не зависят от рабочей директории
- `_sanitize` экранирует `&` (раньше только `<`/`>`)
- `.env.example` перенесён в корень репозитория (рядом с docker-compose, который читает `.env`)
- Неверный URL репозитория в доках (`MyAstrologV2` → `MyAstrolog`)
- Добавлены тесты: `my_astro_bot/tests/` (calculator, astrology, interpretator, geocoder)
